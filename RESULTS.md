## Random-target benchmark

Generated by `scripts/05_random_target_benchmark.py` and stored under `results/random_benchmark/`.

Key files:

- `metrics_random_targets_all_trials.csv`
- `metrics_random_targets_summary.csv`

## Additional reference outputs

`results/base_inertia_sensitivity/` and `results/scientific_plots/` are retained as reference outputs from the supplied supplementary-material package. The supplied script set does not contain a dedicated script that regenerates all files in these two folders, so treat them as precomputed reference material rather than outputs covered by the replication commands in the main README.

## Quick numerical check

For the supplied random-target benchmark summary (`30` trials per controller), the reference mean final position errors are approximately:

| Controller | Mean final error (m) | Precision success rate | Base-stable success rate |
|---|---:|---:|---:|
| CLIK | 0.3364 | 0.2667 | 0.0000 |
| DLS | 0.3094 | 0.3000 | 0.0000 |
| Fixed-RNS | 0.2913 | 0.3333 | 0.0333 |
| ReAct-NS | 0.1980 | 0.6667 | 0.2667 |

Small differences can occur across platforms or dependency versions. Use the included CSV files as the primary reference.
